## 状态、认证和数据迁移

新增 APP_STATE / AppStateDO（迁移 v3）。首次启动把旧 SIMPAGE_DATA:data 迁入 SQLite Durable Object，之后统一串行检查版本并事务提交；旧 KV 不写入、不删除。后台一次保存变成一次批量 PATCH，带 _version、稳定条目 ID 和 requestId，重复请求不会新增重复条目，版本冲突保留编辑内容。

改密码会提升会话版本并为当前设备重发 Cookie，其他会话立即失效；退出即时撤销。旧 KV 会话只在首次迁移后最多 12 小时内兼容，改密后永久关闭这个入口。最多保留 256 条会话，15 分钟周期清理过期记录；最近 128 条保存回执用于去重。登录/改密按 IP 在计算密码前原子预占额度，每 5 分钟最多 5 次，包括成功尝试；记录到期清理，旧全局限流对象的历史记录在迁移时清理。

新保存整份数据上限 512 KiB、每个集合最多 1000 项、天气最多 8 城市；超限返回明确错误，不截断数据。旧 KV 超过 1.5 MiB 或无法解析时停止迁移并保留源数据。迁移后的新修改不再同步回旧 KV，因此不应直接回滚到旧版继续编辑；需要回退时，应先导出最新权威数据并设计反向迁移。

配置缓存与访客计数缓存分开，访客不再延长配置寿命；旧请求不能覆盖更新版本。原非原子 get/检查/put 写入方案已移除。前端迁移到批量保存后，旧全量 PUT 和单分区 PATCH 的重复实现也已移除；旧路径通过鉴权后统一返回 410，提示刷新管理页面，避免旧页面继续写数据。

## 前端及公共模块

- 保存/读取期间锁定相关编辑，冲突和失败保留草稿；未知结果重试复用请求编号。退出按钮恢复，错误响应不再显示退出成功。
- 弹窗图标请求可取消并检查条目/URL/弹窗版本；改密成功同步编辑器版本，保留尚未保存的草稿。
- shared.js 统一设置、城市分隔去重、页脚和字段规则；image.js 统一图片超时/取消；图标 DOM 创建和 favicon 使用共同规则，支持安全的根相对图片地址。
- 公共 JSON 请求覆盖响应体读取期限，支持调用者取消；写超时标注结果未确认，不自动重试。
- 日期/农历按日缓存，周数按整日计算；本地搜索不重建隐藏分区，后台编辑只重绘目标集合，图标延迟解码/加载。
- favicon 对同一设置去重，字符图片缓存限制为小容量；主题存储异常只降级记忆功能，不再阻断首页。
- Markdown 分离链接目标与文本强调处理，保留正常下划线/query，同时转义 HTML 并拒绝执行协议。
- 移除不被读取的进度 CSS 变量、旧页脚搬移逻辑及天气不可达分支。

## 上游请求与工具链

天气、壁纸和图标请求拆到 server/upstream.mjs，测试可直接导入，无需切割这几组源码。天气超时覆盖响应体，JSON 限大小；缓存故障可降级，负缓存命中不反复等待重试。相同天气请求有在途合并和容量上限。

壁纸同一 isolate 的并发冷请求共享一次有大小限制的下载；可用旧图直接返回并后台刷新。共享对象为不可变 Blob，每次创建独立响应；缓存写入不再阻塞成功图片，后台写入也有独立期限。原有 HTTPS 域名/跳转/类型/大小防护保持。自动图标仅向固定服务发送目标 origin，拒绝 URL 中账号密码，不传私有路径、查询及片段。

工具链锁定 Wrangler 4.158.0、配套 Miniflare 5.20261104.0-beta（与该 Wrangler 依赖版本一致）及静态资源处理器 0.5.0，声明 Node >=22，.node-version 指定 Node 24。本次在 Node 24.22.1 验证，未修改系统 Node。依赖复查为 0 个已知漏洞。
